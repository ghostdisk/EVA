# Security policy

EVA runs untrusted code and processes untrusted assets. Any way for content to corrupt memory, take control of the
engine, or get unsafe input to the GPU driver is a security issue.

## Reporting a vulnerability

Please email **alex@panzermail.com** instead of opening a public issue, with an input or steps that reproduce it, the
commit, and what happens. Please allow time for a fix before disclosing it publicly.

## Supported versions

EVA is in early development. Only the latest `main` gets fixes.
